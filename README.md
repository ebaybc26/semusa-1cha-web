# 세무사 1차 기출 스터디

2023·2024·2025년(제60~62회) 세무사 1차 시험 기출문제 479문항을 과목·단원별로 풀어볼 수 있는 단일 HTML 웹앱입니다.

**바로 풀기 →** https://ebaybc26.github.io/semusa-1cha-web/

## 안내
- **정답**은 큐넷 공식 최종정답과 479문항 전수 대조해 일치를 확인했습니다. 전항정답·복수정답 문항 3개도 복수 정답으로 처리돼 있습니다.
- **단원 분류와 참고 메모는 공식 자료가 아니라 임의로 붙인 것**입니다. 학습 편의를 위한 분류이며 출제기관의 분류와 다를 수 있습니다.
- 문제 지문·선택지의 저작권은 출제기관인 한국산업인력공단(큐넷)에 있습니다. 개인 학습 용도로만 이용해 주세요.
- 풀이 기록은 브라우저(localStorage)에만 저장됩니다. 서버로 전송되지 않으며, 기기를 바꾸면 이어지지 않습니다.

## 사용법
`index.html` 파일 하나로 동작합니다. 내려받아 브라우저로 열어도 그대로 쓸 수 있습니다.
